# portfolio
A personalised website detailing information about myself and the projects I am working on

This portfolio is also a project in itself as a way to practice vibe coding, manual coding, and the acquisition of new skills.

Through this first iteration, I have used Claude as a tool to create a personal and stylised website with a more creative aesthetic. I've learnt a lot about design and the limitations of LLMs in creative spaces.

The next stage of this project is to slowly learn to manually code in HTML, CSS, and Javascript. The end result that I am hoping for is the ability to recreate this website manually and to have the ability to compare the quality of the code in both examples. I expect the second part of this project to take a very long time
